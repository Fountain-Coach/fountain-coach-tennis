# Fountain Coach Tennisrunde

Diese URL beschreibt eine Tennis-Spielplan-App in deutscher Sprache.

## Lesbare Informationen

Die App kann Spieltage, Spieler, Abwesenheiten, Fixzeiten, Begegnungen, Fairnesswerte und Validierungszustände
anzeigen. Der Nutzer muss den Spielplan im Browser erzeugen, bevor lokale Spielplandaten vorhanden sind.

## Aktionsgrenze

Diese URL erteilt ChatGPT keine Schreibberechtigung. Für Fragen kann ein authentifizierter Read-Endpunkt genutzt
werden. Änderungen durch ChatGPT laufen ausschließlich über den authentifizierten MCP-Endpunkt und dessen von
ChatGPT angezeigte Bestätigungsschranke.

## Integration

Discovery: `/.well-known/fountain-coach-tennis.json`
Human entry point: `/`
MCP endpoint: `/mcp` (Streamable HTTP)
Read API: `/api/state` (Bearer authentication)
Current status: public HTTPS deployment, GitHub admin OAuth, MCP discovery, OAuth metadata, PKCE, dynamic client
registration, and the protected MCP challenge are verified. The final ChatGPT workspace/app connection is completed
from ChatGPT Developer Mode because ChatGPT must own the dynamic client registration and user consent.

## ChatGPT connection

In ChatGPT Developer Mode, create a Custom App with the deployed HTTPS MCP endpoint
`https://tennis.fountain.coach/mcp`. Let ChatGPT scan the endpoint and choose OAuth when prompted. The app is served
over HTTPS and exposes the OAuth authorization-code flow (PKCE, dynamic client registration, explicit admin consent,
resource/audience propagation, and refresh tokens). The admin identity must be listed in
`TENNIS_ADMIN_EMAILS` or `OAUTH_ADMIN_EMAILS`. A static bearer credential remains only an owner-approved compatibility
lane. Mutating tool calls require the `tennis.write` scope and `confirm: true`; the user must approve the mutation at
the ChatGPT boundary before that flag is sent. The URL of the human web app is not itself an action endpoint.

The server also trusts exactly one reverse-proxy hop for Caddy's forwarded client address. This is required for the
rate limiter to operate correctly behind the production edge; it does not grant the proxy application access.

After ChatGPT completes OAuth, verify the app can call the read-only MCP tools before testing writes. Approve each
write confirmation explicitly; do not paste GitHub client secrets or bearer tokens into ChatGPT configuration.

The configured upstream provider may be GitHub (`OAUTH_IDP=github`, `GITHUB_OAUTH_CLIENT_ID`,
`GITHUB_OAUTH_CLIENT_SECRET`, `GITHUB_OAUTH_REDIRECT_URI`), Google, or Apple. GitHub identities are admitted only
when the provider returns a verified email present in the admin allowlist.
