# Zugang als zweiter Organisator

Hallo!

du sollst einen eigenen Zugang zur Tennis-Anwendung bekommen. Dafür brauchst du
nur deinen persönlichen GitHub-Account. Es ist kein Passwort, kein GitHub-Token
und kein Zugriff auf den Quellcode nötig.

## Was du bitte zurückschickst

Bitte trage in der beigefügten Beispieldatei ausschließlich die E-Mail-Adresse
ein, die GitHub bei deiner Anmeldung für diesen Account verwendet. Schicke die
Datei anschließend zurück oder teile mir die Zeile auf einem sicheren Weg mit.

Beispiel:

```text
dein-github-name@example.com
```

Die Adresse ist nur dafür da, deinen GitHub-Login dem richtigen Zugang in der
Tennis-Anwendung zuzuordnen. Sie wird nicht im öffentlichen Repository
veröffentlicht.

## So meldest du dich später an

1. Öffne `https://tennis.fountain.coach`.
2. Wähle **Mit GitHub anmelden**.
3. Melde dich mit genau dem GitHub-Account an, dessen verifizierte E-Mail du
   mitgeteilt hast.

Als Organisator siehst du den gemeinsamen Spielplan und darfst ihn bearbeiten.

## Bitte nicht mitsenden

Bitte niemals GitHub-Passwörter, persönliche Zugriffstoken, OAuth-Schlüssel,
private Schlüssel oder andere Zugangsdaten in diese Datei schreiben. Auch
Spielerlisten, private Notizen oder Exportdateien gehören nicht in dieses Paket.

Falls sich deine GitHub-E-Mail ändert oder du keinen Zugang mehr haben sollst,
gib kurz Bescheid. Der Zugang kann dann ohne Änderung deines GitHub-Accounts
angepasst oder entfernt werden.

Vielen Dank — wir halten den Zugang bewusst einfach und verwenden nur die
Information, die für die Zuordnung deines Logins wirklich erforderlich ist.
