# Public seed privacy record

This repository is a public customer-facing seed. Before export from the private workspace:

- participant names were replaced with generic labels (`Spieler 01` through `Spieler 12`);
- participant absence dates were removed;
- local audit/runtime state was excluded;
- generated ZIP artifacts were excluded;
- `node_modules`, OS metadata, credentials, and local deployment material were excluded;
- no OAuth client ID, client secret, bearer token, cookie, or session value was copied.

The scheduling algorithm, UI structure, terminology, calculations, validation rules, integration contracts, and tests remain present. The generic labels are public starter fixtures, not real users.

This is a technical publication record, not a legal opinion. Before production operation, the owner must establish the controller/processor roles, privacy notice, retention and deletion rules, user-rights handling, incident contact, and jurisdiction-specific review described in `app/SECURITY.md`.
